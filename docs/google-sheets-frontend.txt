Frontend connection flow:
1. GET https://hostapi.soft7.in/v1/admin/google-sheets/connection with the existing
   dashboard owner JWT. An unauthorized response must be shown as an auth error.
2. On Connect Google, POST /v1/admin/google-sheets/oauth/start with the same JWT,
   credentials: 'include' (Axios: withCredentials: true). The browser supplies Origin.
3. Open the returned data.authorization_url in a popup or navigate to it. Keep the
   dashboard's current flow editor state. The callback returns JSON, not a frontend
   redirect or postMessage. The dashboard can poll /connection while the popup is open
   and refresh the connection selector when connected becomes true. Stop polling on
   success, cancellation, timeout, or when leaving the screen.
4. After authorization, select the connection and retry the spreadsheet action.
   Use /setup for Picker configuration and /picker-token for a short-lived token.
   Never log authorization URLs, OAuth codes, state values, or tokens.

Third-party cookie restrictions can prevent the browser-session cookie from reaching
the API callback on unrelated domains. A same-site API proxy is needed where browsers
block that cookie; adding CORS origins alone does not override browser restrictions.

Troubleshooting: inspect the Network request URL, status and CORS response. A generic
Network Error alone cannot establish its cause. origin_mismatch is a Google client
origin setting; redirect_uri_mismatch concerns the backend callback URI above. A 401
means the dashboard JWT is missing/invalid; team members cannot connect as the owner.
