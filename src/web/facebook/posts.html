Meta App Review recording guide
  1. Sign in with the supplied application test login. Click Connect Facebook Page, authorize the requested permissions, select a Page you manage and connect it.
  2. For pages_read_user_content, add a real comment to a Page post from another Facebook account. In this workspace click Open Page, Refresh feed, Read comments and Refresh comments. Show the same comment in Facebook and in this app. If your Page accepts visitor posts, you can also demonstrate a visitor post in the feed.
  3. For pages_manage_posts, enter a text update and click Publish to Facebook. Refresh feed and open View on Facebook to show the result. Edit the app-created post, verify it on Facebook, then delete it only if you intend to remove it.

We request pages_show_list and pages_read_engagement to select the managed Page and read its posts. This workspace reads visitor content and comments; comment replies and moderation are not included.
